What Makes GateClaw Different

Not another chatbot. GateClaw is a resident AI entity that lives on your machine, remembers everything, and actually does things.

🧠

Persistent Memory

SQLite database stores facts indefinitely. GateClaw remembers your preferences, API keys, workspace paths, and conversation context across sessions. Unlike chatbots that forget everything.

👤

Soul Identity

SOUL.md defines GateClaw's personality. Direct, technical, slightly sarcastic. You control the identity. Edit the frontmatter to change tone, traits, and behavioral patterns.

🎭

5 Interfaces

Telegram bot (mobile), TUI (terminal), CLI (daemon), Web UI (browser), HTTP API (programmatic). Same resident AI, different access methods. Choose your interface.

🏠

Local-First

Runs on your hardware. Your data stays local. No cloud dependency. No telemetry. GateClaw is a resident, not a service. Air-gapped deployment supported.

📁

File Operations

Read/write files in your workspace. Parse JSONC configs, manage .env files, extract secrets, modify system files. GateClaw sees what you allow it to see.

⚡

Shell Execution

Execute commands via CMD, PowerShell, bash. GateClaw becomes your terminal with persistent memory and context awareness. Daemon control, provider management, automation.
