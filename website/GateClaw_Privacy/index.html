🛡️ Trust & Transparency

Privacy & Security

GateClaw is local-first by design. Your data never leaves your machine unless you explicitly allow it. Enterprise-grade security, GDPR compliance, and full audit transparency.

🛡️

Privacy Principles

Core commitments that guide GateClaw's design and development.

🏠

Local-First Architecture

GateClaw runs on your machine. Your files, memory, and conversations stay local. No cloud dependency, no data exfiltration, no phone home. You own your data.

🔐

Memory Encryption

SQLite facts are encrypted at rest. API keys and credentials use AES-256 encryption. Memory access requires authentication. Your secrets stay secret.

📋

Full Audit Logging

Every file operation, shell command, and API call is logged. Exportable audit trails for compliance. Know exactly what GateClaw did and when.

🔓

Open Source Transparency

100% open-source codebase. No hidden telemetry, no backdoors, no data collection. Audit the code yourself. Trust through transparency.

⚙️

User Consent Model

Explicit consent for sensitive operations. Shell commands require review. File writes confirm paths. API keys entered by you, not harvested.

🗑️

Data Deletion Rights

Delete any fact, clear all memory, purge audit logs. You control retention. GDPR right to erasure built-in. One command: `gateclaw memory purge`.

🔒

Security Features

Enterprise-grade security controls protecting your data and operations.

🔐

Encryption at Rest

All persistent data encrypted using AES-256-GCM. SQLite database encrypted via SQLCipher. Credentials stored in encrypted vault.

  • AES-256-GCM encryption
  • SQLCipher for SQLite
  • Key derivation: PBKDF2
  • Zero plaintext storage
🔑

Credential Vault

API keys, tokens, and passwords stored in encrypted vault. Never logged, never transmitted. Platform keychain integration available.

  • Encrypted credential storage
  • Platform keychain support
  • No plaintext logging
  • Rotation support
📝

Audit Logging

Every operation logged: timestamp, operation type, resource, result. Exportable for compliance. Retention configurable. Immutable logs.

  • Immutable audit trail
  • Configurable retention
  • Export formats: JSON, CSV
  • SIEM integration ready
🚫

Allowlist Mode

Restrict file paths, shell commands, and API endpoints. Production environments can enforce strict allowlists. Prevent unauthorized operations.

  • Path allowlists
  • Command allowlists
  • API endpoint restrictions
  • Environment enforcement
👤

Access Control

Role-based access control for multi-user deployments. Separate memory per user. Permission escalation requires approval.

  • RBAC support
  • User memory isolation
  • Permission escalation review
  • Session management
🔍

Vulnerability Scanning

Dependencies scanned via Snyk, Dependabot. Security advisories monitored. CVE tracking. Automated patching for critical vulnerabilities.

  • Snyk integration
  • Dependabot monitoring
  • CVE tracking
  • Auto-patch critical CVEs
🌐

Network Isolation

Local-first means no outbound connections by default. Explicit allowlist for API calls. Firewall rules documented. Air-gapped deployment supported.

  • No default outbound traffic
  • API allowlist mode
  • Firewall documentation
  • Air-gap support
🔄

Secure Updates

Code-signed releases. SHA-256 checksums verified. Update server pinned. Man-in-the-middle protection. Rollback support for failed updates.

  • Code signing
  • SHA-256 verification
  • Certificate pinning
  • Rollback support
